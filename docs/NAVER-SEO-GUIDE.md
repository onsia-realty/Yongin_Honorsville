## ✅ 1단계: 네이버 서치어드바이저 등록 (필수)

### 1.1 사이트 등록

**URL**: https://searchadvisor.naver.com/

**절차**:
1. 네이버 계정으로 로그인
2. "사이트 등록" 클릭
3. 사이트 URL 입력: `https://yongin-honorsville.vercel.app`
4. 소유 확인 방법 선택

### 1.2 소유 확인 방법 (3가지 중 선택)

#### 방법 1: HTML 태그 (추천 - 가장 쉬움)

네이버가 제공하는 메타 태그를 `app/layout.tsx`에 추가:

```typescript
// app/layout.tsx
export const metadata: Metadata = {
  // 기존 코드...
  verification: {
    google: 'google-site-verification-code',
    naver: '21e431fabface3d904e1968338dd3fd66dd05ba3', // ✅ 이미 있음!
  },
}
```

**현재 상태**: 이미 네이버 인증 코드가 있습니다! ✅
- 코드: `21e431fabface3d904e1968338dd3fd66dd05ba3`
- 이 코드로 서치어드바이저에서 확인만 하면 됩니다.

#### 방법 2: HTML 파일 업로드

```html
<!-- public/naver[인증코드].html -->
naver-site-verification: naver[인증코드].html
```

#### 방법 3: DNS TXT 레코드 (도메인 설정 필요)

도메인 DNS 설정에 TXT 레코드 추가

### 1.3 사이트맵 제출

서치어드바이저에서:
1. "요청" 메뉴 → "사이트맵 제출"
2. URL 입력: `https://yongin-honorsville.vercel.app/sitemap.xml`
3. 제출 완료

**확인**: 현재 사이트에 sitemap.xml이 있습니다 ✅

### 1.4 RSS 피드 제출 (선택)

블로그 기능 구축 후 RSS 피드도 제출하면 더 빠른 수집 가능

## ✅ 2단계: 네이버 최적화 작업

### 2.1 메타 태그 최적화

네이버는 다음 메타 태그를 중요하게 봅니다:

```html
<title>클러스터용인 경남아너스빌 | 반도체 프리미엄 직접 영향권</title>
<meta name="description" content="용인 반도체클러스터 중심, 삼성·SK 10분대 프리미엄아파트. 경남아너스빌 997세대 대단지 분양">
<meta name="keywords" content="경남아너스빌, 클러스터용인, 용인아파트, 반도체클러스터">
<meta property="og:title" content="클러스터용인 경남아너스빌">
<meta property="og:description" content="용인 반도체클러스터 프리미엄 아파트">
<meta property="og:image" content="https://yongin-honorsville.vercel.app/대표홈페이지 썸네일.jpg">
```

**현재 상태**: 이미 잘 구현되어 있습니다 ✅

### 2.2 페이지별 고유 메타데이터 (중요!)

**문제**: 모든 페이지가 동일한 메타데이터 사용 중

**해결**: 각 페이지에 고유한 title, description 추가

```typescript
// app/business/page.tsx
export const metadata: Metadata = {
  title: '사업개요 | 클러스터용인 경남아너스빌',
  description: '경남아너스빌 용인 프로젝트 사업개요. SK하이닉스 10분대, 997세대 대단지',
  keywords: '경남아너스빌, 용인아파트, 사업개요',
}
```

### 2.3 구조화된 데이터 (JSON-LD)

네이버도 Schema.org를 지원합니다:

```typescript
// components/schema/RealEstateAgentSchema.tsx

  "@context": "https://schema.org",
  "@type": "RealEstateAgent",
  "name": "클러스터용인 경남아너스빌",
  "url": "https://yongin-honorsville.vercel.app",
  "telephone": "1668-5257",
  "address": {
    "@type": "PostalAddress",
    "streetAddress": "양지면 양지리 697번지",
    "addressLocality": "용인시 처인구",
    "addressRegion": "경기도",
    "addressCountry": "KR"
  }
}
```

## ✅ 3단계: 네이버 플랫폼 활용 (백링크 전략)

### 3.1 네이버 블로그 운영 (가장 효과적!)

**왜 중요한가?**
- 네이버는 자사 플랫폼(블로그, 카페) 콘텐츠를 우대합니다
- 블로그에서 메인 사이트로 링크 = 강력한 백링크

**실행 방법**:

1. **네이버 블로그 개설**
   - 블로그명: "클러스터용인 경남아너스빌 공식 블로그"
   - URL: blog.naver.com/[아이디]

2. **주 2-3회 포스팅 (AI 활용)**
   ```
   제목 예시:
   - "용인 반도체 클러스터 아파트 경남아너스빌, 입지 분석"
   - "경남아너스빌 84㎡ vs 123㎡ 평면도 비교"
   - "SK하이닉스 10분대 프리미엄 아파트 투자 가이드"
   ```

3. **본문에 메인 사이트 링크 3-5개 포함**
   ```
   자세한 정보는 [클러스터용인 경남아너스빌 공식 홈페이지]에서 확인하세요.

   👉 사업개요: https://yongin-honorsville.vercel.app/business
   👉 평면도: https://yongin-honorsville.vercel.app/floor-plan
   👉 분양 일정: https://yongin-honorsville.vercel.app/sales-schedule
   ```

4. **이미지 풍부하게**
   - 10장 이상 삽입 (네이버가 선호)
   - 이미지 alt 텍스트에 "경남아너스빌" 포함

### 3.2 네이버 카페 활용

**대상 카페**:

- 경기도 아파트 카페

**포스팅 전략**:

## ⚠️ 네이버 특수성 주의사항

### 1. 네이버는 자사 플랫폼 우대
- 네이버 블로그, 카페가 상위 노출됨

- 새 도메인은 초기 순위 낮음
- 시간이 지날수록 신뢰도 상승
- **해결**: 꾸준한 콘텐츠 업데이트
